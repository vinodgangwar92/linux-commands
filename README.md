# Linux Commands

This repository contains my Linux command practice for DevOps learning.

## Topics Covered
- File and directory commands
- User and permission commands
- Process management
- Disk and memory checks
- Networking commands

## Basic Commands

```bash
pwd

cd /home
mkdir test-folder

cp file.txt backup.txt
mv backup.txt old-backup.txt
rm old-backup.txt
